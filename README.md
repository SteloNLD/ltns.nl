# ltns.nl

Source for [ltns.nl](https://ltns.nl) — a digital garden by Sten Lootens.

For how the garden is structured, how notes are named, and what goes where, see [How this garden works](content/notes/how-this-garden-works.md).

## SSGs

Hugo and Zola are kept as parallel proof-of-concept targets. Quartz is the planned end-game.

```
ci/preprocess.py hugo   # build Hugo
ci/preprocess.py zola   # build Zola
```
